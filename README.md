## 3. 個人問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
在測試一中，桌遊原始名單的 `" Amy"` 和 `"amy"` 經過轉小寫與移除空白後，其實是同一個人重複報名。根據活動規則，同一人在同一場活動中只算一位參加者、也只收一次費，因此必須以去重後的 **3 人**計算（$3 \times 120 = 360$ 元）。
* **轉成 `list`**：**保留**了所有人的原始報名順序與重複紀錄（能看出誰重複報名），但**失去**了自動過濾重複資料的功能，直接用來計算會導致重複收費。
* **轉成 `set`**：**保留**了不重複的獨立參加者名單，且能直接進行交集、聯集與差集運算；但**失去**了原本的報名順序、重複次數以及位置索引（需搭配 `sorted()` 才能依字母順序顯示）。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
在測試三中，桌遊與電影去重後的集合皆為 `{'amy', 'ben', 'cora'}`（兩集合完全相等，即 $A = B$）。
* **總不重複人數（3 人）**：代表兩場活動的**聯集**（$A \cup B$），因為兩場參加者完全重疊，聯集後依然只有 3 位獨立參加者。
* **報名人次（6 人次）**：因為兩場活動分開報名與計費，這 3 位參加者同時屬於兩場的**交集**（$A \cap B$），每個人都參加了兩場，因此總人次為「桌遊去重人數 $3$ ＋ 電影去重人數 $3$ ＝ $6$ 人次」。
* **總應收（600 元）**：兩場活動依各自參加人數獨立計算費用，桌遊應收 $3 \times 120 = 360$ 元，電影應收 $3 \times 80 = 240$ 元，合計總應收為 $360 + 240 = 600$ 元。
